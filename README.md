# QBR Prep Agent

A learning project: an agent that checks a customer account's health and prepares QBR talking points.

## Setup (Mac, run in Terminal from this folder)

    python3 -m venv .venv
    source .venv/bin/activate
    pip install -r requirements.txt
    export ANTHROPIC_API_KEY="paste-your-key-here"

## Run

    python3 agent.py
